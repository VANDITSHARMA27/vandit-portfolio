# Vandit Sharma — Portfolio

Next.js + Three.js + Motion portfolio, statically exported and deployed to GitHub Pages.

## Edit your content
All text lives in `content/` (site.ts, experience.ts, projects.ts, skills.ts, certifications.ts, education.ts, impact.ts).
Hero/about copy: `content/site.ts` and `components/scenes/AboutScene.tsx`.

## Run locally
    npm install
    npm run dev      # http://localhost:3000

## Deploy
Push to `main`. In the repo: Settings → Pages → Source: **GitHub Actions**.
